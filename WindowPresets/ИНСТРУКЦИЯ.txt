WINDOWPRESETS 0.6.0 — МЕНЕДЖЕР РАБОЧИХ ПРОСТРАНСТВ WINDOWS
================================================================
Автор: NickMoor, 2026. Запуск: WindowPresets.exe (портативно,
всё хранится рядом с exe) или py -3.14 main.py (исходники).


--- ЧТО ДЕЛАЕТ ПРОГРАММА ---------------------------------------

Сохраняет снимок рабочего места: окна (позиции, мониторы),
запущенные программы, папки проводника (с вкладками Win11).
Одной кнопкой восстанавливает рабочее место.


--- ГЛАВНОЕ ОКНО ------------------------------------------------

Список пресетов сгруппирован: «1 монитор» / «Несколько
мониторов» (по числу мониторов В МОМЕНТ сохранения пресета).

Кнопки под списком:
- «+» Новый пресет — снять текущее рабочее место;
- значок программы — Загрузить — применить выбранный пресет;
- «↻» Обновить — пересканировать окна и обновить пресет;
- «✕» Закрыть — закрыть окна/папки пресета (программа не закрывается);
- «🗑» Удалить пресет (с подтверждением); Ctrl+клик по корзине —
  Удалить ВСЕ пресеты (усиленное подтверждение);
- «⚙» Настройки (внизу справа, рядом со строкой состояния).


--- ДЕЙСТВИЯ С ПРЕСЕТОМ (правый клик) --------------------------

- Загрузить — применить пресет;
- Настроить — окно состава: галочками отметить лишние программы
  и папки -> «Удалить выбранные» (пресет обновится без пересканирования);
- Дублировать — копия «X (копия)» сразу за оригиналом;
- Закрыть окна пресета;
- Обновить из текущих окон — пересканировать;
- Переименовать (или двойной клик по строке);
- Удалить (с подтверждением);
- Тег (вкладка)... — отметить вкладки-фильтры пресета галочками;
- Цвет — свой цвет-подложка пресета (палитра / любой / по умолчанию);
- Добавить разделитель — строчка-заголовок под этим пресетом
  (на пустом месте списка — в конец).

Порядок пресетов — перетаскиванием мышью.


--- ЗАГРУЗКА ПРЕСЕТОВ ------------------------------------------

- Обычный клик «↓» — окна пресета поверх текущих;
- Ctrl+клик — полное восстановление: закрыть лишние окна,
  которых нет в пресете;
- несколько выделенных пресетов грузятся ПО ОЧЕРЕДИ (плашка
  «Загружаю...» показывает прогресс N/M);
- загрузка не блокирует окно программы.


--- МУЛЬТИВЫДЕЛЕНИЕ --------------------------------------------

Ctrl+клик — добавить/убрать, Shift+клик — диапазон.
Ко всем выделенным разом: загрузка, удаление, теги, цвет,
перетаскивание. Правый клик по выделенному не сбрасывает
выделение; по невыделянному — выделяет только его.


--- РАЗДЕЛИТЕЛИ -------------------------------------------------

Строчки-заголовки для каталогизации: правый клик ->
«Добавить разделитель» (сразу просит имя). Ничего не грузят,
превью нет. Можно красить, перетаскивать, дублировать,
переименовывать, удалять. Локальны для вкладки, где созданы
(в «Все» — видны только в «Все»). Текст разделителя
центрируется по горизонтали.


--- ВКЛАДКИ-ФИЛЬТРЫ --------------------------------------------

Вкладки сверху — фильтры по тегам; «Все» показывает всё.
Кнопки справа от вкладок:
- «+» создать, «⧉» дублировать (с пресетами), «⌶» переименовать,
  «🗑» удалить (Ctrl+клик — ВСЕ вкладки);
- режим значки/текст — галочка в настройках «Главное окно».

Перетаскивание — порядок вкладок. Колесо мыши над вкладками —
листание. Правый клик по вкладке: дублировать / переименовать /
удалить / Цвет (подложка плашки). Двойной клик по обычной
вкладке — переименовать её.

Клик по плашке текущей вкладки (над списком) — всплывающий
список всех вкладок: ЛКМ — переключить, ПКМ — меню, перетаски-
вание — порядок; закрытие — клик вне.

Двойной клик по «Все» — БЫСТРЫЙ ПОИСК (см. ниже).


--- БЫСТРЫЙ ПОИСК ПРЕСЕТОВ -------------------------------------

Двойной клик по вкладке «Все»: окно со всеми пресетами и
строкой поиска. Печатай — фильтр; Enter / клик — выбор: список
прокручивается к пресету и выделяет его (скрытый во вкладке —
программа переключит вкладку). Окно растёт под количество,
дальше — колонки (ширина колонки = окно программы); упёрлось
в монитор — колесо мыши листает страницы. Закрытие: курсор
вне окна, Esc, выбор. У ячеек — цвет пресета и полоски вкладок.


--- ПРЕВЬЮ ------------------------------------------------------

Наведение курсора на строку пресета — малое превью рядом со
списком: скриншот + состав (программы со значками, папки,
сводка). Пресет в нижней половине списка — текст сверху,
скриншот снизу. Длинный состав скроллится.

Раскрыть на весь экран:
- навести курсор на СКРИНШОТ малого превью и держать;
- или навести на скриншот и нажать ПРОБЕЛ (держать).

Пока открыто любое меню/окно программы — превью не раскрывается.


--- НАСТРОЙКИ ---------------------------------------------------

Раздел «Язык / Language»:
- Русский / English — язык всего интерфейса; смена применяется
  сразу, окно настроек перезапускается на выбранном языке.
  Имена пресетов, вкладок и разделителей — ваши данные,
  никогда не переводятся.

Раздел «Автозапуск»:
- Запускать при старте системы — автозапуск через реестр.

Раздел «Главное окно»:
- Использовать цвет системы — цвета под тему Windows
  (тёмная/светлая); бегунки яркости при этом не действуют;
- Поверх всех окон — окно поверх остальных (плашка загрузки —
  всегда поверх независимо от галочки);
- Яркость главного окна / Яркость списка пресетов (0–255);
- Прозрачность цвета пресетов (0–100 %) — плотность цветных
  подложек пресетов и разделителей;
- Кнопки вкладок — значки (иначе текст).

Раздел «Иконки»:
- Яркость иконок и Размер иконок (в %) — действуют сразу на
  нижние кнопки пресетов и на верхние кнопки вкладок;
  верхние жёстко привязаны к нижним: та же яркость,
  размер — 70 % нижнего. Пак иконок один, единственный.

Раздел «Превью»:
- Показывать превью;
- Размер текста инфо-плашки; Прозрачность инфо-плашки;
- («Размер превью» и «Затемнение» пока не действуют.)

Раздел «Поведение»:
- Сворачивать в трей (крестик прячет в трей, а не закрывает);
- Запоминать положение окон.

Раздел «Пути запуска»:
- ручные пути/команды для программ пресета (например, запуск
  в песочнице: "SandMan.exe" /box:DefaultBox "программа.exe").

Раздел «Исключения программ»:
- программы и папки, которые НЕ сохранять в пресеты
  (выбор из открытых окон с значками или вручную).

Внизу настроек: «Проверить обновления» и блок автора.

Пасхалка: в самом низу настроек — «Кавабанга !»


--- ОБНОВЛЕНИЕ С GITHUB ----------------------------------------

Кнопка «Проверить обновления»: сравнивает версию с последним
релизом на GitHub; при наличии — скачивает и подменяет exe
(программа закроется и запустится новой). Нужен интернет.


--- ТРЕЙ И ОКНО ------------------------------------------------

- Повторный запуск не создаёт копию — поднимает открытое окно;
- значок в трее: ЛКМ — показать, ПКМ — Показать / Настройки /
  Выход;
- крестик: свернуть в трей (галочка «Поведение») или закрыть;
- окно/меню программы всегда целиком в границах монитора;
- лог диагностики: logs/app.log рядом с exe.


--- ДАННЫЕ ------------------------------------------------------

Рядом с exe (или скриптом): presets.json — пресеты; config.json
— настройки; previews/ — скриншоты; logs/ — логи. Копируй папку
целиком для переноса. Ручное редактирование — на свой риск.


--- КЛАВИШИ (СВОДКА) -------------------------------------------

- ПРОБЕЛ (держать, курсор на скриншоте превью) — превью на весь
  экран;
- Ctrl + «Загрузить» — полное восстановление;
- Ctrl + клик по корзине пресетов — удалить все пресеты;
- Ctrl + клик по корзине вкладок — удалить все вкладки;
- Ctrl/Shift + клик по списку — мультивыделение;
- Esc — закрыть окно быстрого поиска.
