## 1. Что за программа (коротко)

WindowPresets — менеджер рабочих пространств Windows (PySide6
6.11.1 + pywin32 312 + psutil, Python 3.14, G:\MY\Neiro\GPT\
WindowPresets). Сохраняет снимок рабочего места (окна с
координатами/мониторами, программы, папки, вкладки проводника
Win11) и восстанавливает одной кнопкой. Обычный клик «Загрузить» —
поверх текущих окон; Ctrl+клик — полное восстановление (закрыть
лишнее). ПКМ по пресету — все действия. Вкладки сверху —
фильтры-теги. Запуск: run.bat (или py -3.14 main.py).

ГЛАВНОЕ ПРАВИЛО СЕССИИ: работаем через run.bat, exe НЕ
пересобираем (устарел с середины сессии; пересборка — только по
просьбе владельца, build_exe.bat).

  GetConsoleWindow (ctypes).
- Sandboxie-Plus: ярлыки SandMan /box:<Box> "..."; заголовки «[#]».
- OBS у владельца от админа — его окна двигает только админ.
- Git: user muraga, gh нет. Тег v0.4.0-stable (откат).
- Логи диагностики: logs/app.log (INFO, с v0.4.4; utf-8).

## 3. Концепции ядра

- Клавиша раскрытия превью — всегда ПРОБЕЛ (зашито; до 03.09 был
  SHIFT). Пробел НЕ модификатор: «всё ещё зажата» — через
  win32api.GetAsyncKeyState(VK_SPACE), не queryKeyboardModifiers.
  Перехват KeyPress только когда превью ВИДИМО (иначе съедается
  активация кнопки в фокусе — пробел «нажимает» кнопки).
- «Мониторов в пресете» — зафиксированное число при сохранении;
  группы списка «1 монитор»/«Несколько мониторов».
- Вкладки = фильтры-теги: config `preset_tabs` [имена] (порядок =
  порядок пользователя, сортировки НЕТ), `Preset.tags` у пресета,
  `tab_colors` {имя:"#hex"}. «Все» встроена, неизменяема,
  НЕ хранится в config.
- Порядок пресетов = порядок в presets.json (владелец тащит
  мышью; алфавитная сортировка в PresetRepository.load УДАЛЕНА).
- Дубликаты (пресеты и вкладки) встают СРАЗУ ЗА оригиналом.
- Исключения (ignore_list) и пути запуска (launch_paths) — см.
  настройки; приоритет запуска: ручной путь → автопесочница →
  AUMID → exe-путь (ярлык Пуска → прямой+UAC-fallback) →
  системные → каталог Пуска → startfile; 1 запуск процесса за
  загрузку; микро-окна <60px не запускаются.

    настроек или реализовать (решение владельца).
15. 🔴 i18n: tr() — ТОЛЬКО для UI-строк. Имена пресетов/вкладок
    (кроме встроенной «Все»)/разделителей, теги, пути, заголовки
