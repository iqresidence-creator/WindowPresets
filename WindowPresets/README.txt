WindowPresets — менеджер рабочих пространств Windows

Сохраняет снимок рабочего места (окна с позициями и мониторами,
программы, папки проводника с вкладками) и восстанавливает его
одной кнопкой. Портативная: все данные хранятся рядом с exe.

Запуск: двойной клик по WindowPresets.exe (Windows 10/11, x64).
Установка НЕ требуется. Полная инструкция пользователя:
ИНСТРУКЦИЯ.txt (в этом архиве).

Возможности:
- вкладки-фильтры с цветами; свой цвет пресетов; разделители;
- мультивыделение: загрузка/удаление/теги/цвет разом;
- быстрый поиск пресета (двойной клик по вкладке «Все»);
- превью со скриншотом; полное превью по ПРОБЕЛу;
- редактор состава пресета («Настроить»);
- загрузка в фоне — окно не замирает;
- цвета под тему Windows; автозапуск; трей; один экземпляр;
- проверка обновлений с GitHub (кнопка в настройках).
